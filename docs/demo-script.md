# JD Select 8–9 分钟演示脚本

版本：D 侧预演稿 0.1  
目标时长：8 分 30 秒；上限 10 分钟  
当前模式：页面与健康检查可演示，业务结果为 mock。正式录屏前必须把标有“待真实链路”的镜头替换为真实输入、解析、匹配和保存。

## 3. D 的逐字讲解参考

### Result

“结果页先给出总分，再拆分为必需技能、加分技能和经历证据质量。匹配与缺失技能分开呈现，建议只要求补充真实能力和项目证据。页面固定展示‘匹配分用于辅助判断，不代表录用概率’，避免将规则分误解为录用概率。”

### History

“历史记录展示岗位名称、分数和按浏览器本地时区转换的创建时间。详情始终使用服务端返回的 id，不使用数组下标，所以列表排序变化不会打开错误记录。修改后重新分析应该创建新记录，并保留旧结果作为快照。”

### 异常与测试

“我们把 Loading、请求失败、空历史和不存在详情分开处理。失败时保留输入并允许重试；请求处理中锁定提交，避免连续点击。当前报告清楚区分 mock UI 检查和真实业务验收，未执行的场景不会预填通过。”

## 4. 录屏操作清单

1. 使用脱敏固定样例；关闭通知、聊天窗口和无关标签页。
2. 浏览器缩放 100%，分辨率建议 1920×1080；字体清楚可读。
3. 两个终端预先启动并最小化；录制中不输入密钥。
4. 预先打开首页、测试报告和备用截图；每个操作停留 1–2 秒。
5. 试录目标 8:00–8:45，给卡顿留余量；超过 9:20 优先删重复解释。
6. 录后完整播放，检查声音、字幕、隐私、画面停顿和最终时长。

## 5. 故障回退

- 后端健康检查失败：展示可读错误，说明恢复方法；不要假装在线。
- 真实匹配临时不可用：停止正式录制并修复/切换已验证的本地集成版本；固定 mock 只用于预演和解释页面，不充当真实结果。
- 页面加载异常：使用预先验证的本地地址重开；备用截图仅用于说明，不替代功能演示。
- 视频接近 10 分钟：删除目录浏览和重复状态展示，保留主流程、算法解释和测试证据。
