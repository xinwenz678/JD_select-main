岗位职责
1. 负责公司核心业务系统的服务端设计与开发，使用 Python 语言编写高质量代码；
2. 基于 FastAPI 框架搭建并维护 RESTful API 服务，保障接口稳定与性能；
3. 参与数据库表结构设计与 SQL 查询优化，配合 DBA 完成慢查询治理；
4. 使用 Git 进行代码版本管理，参与 Code Review，维护团队代码规范；
5. 负责服务的容器化部署，编写 Dockerfile 并维护 CI/CD 流水线。

任职要求
1. 本科及以上学历，计算机相关专业，2 年以上 Python 后端开发经验；
2. 熟悉 FastAPI、SQLAlchemy，掌握 MySQL 或 PostgreSQL 等关系型数据库；
3. 熟练使用 SQL，具备复杂查询与索引优化能力；
4. 掌握 Git 常用操作，熟悉 Docker 容器化部署；
5. 了解 Redis 缓存、Kafka 消息队列者加分；
6. 有 Kubernetes 容器编排经验者优先；
7. 具备良好的沟通协作能力与自驱力。
