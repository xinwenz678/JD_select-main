岗位职责
1. 负责公司应用系统的容器化改造与部署，编写并维护 Dockerfile；
2. 负责 Kubernetes 集群的搭建、监控与日常运维；
3. 搭建并维护 CI/CD 流水线，保障代码自动构建与发布；
4. 负责服务器日常巡检、日志分析与故障排查。

任职要求
1. 本科及以上学历，计算机相关专业，2 年以上运维或 DevOps 经验；
2. 熟练使用 Docker，熟悉 Kubernetes 容器编排；
3. 熟悉 Linux 操作系统常用命令，能编写 Shell 脚本完成自动化任务；
4. 熟悉 CI/CD 流程，有 Jenkins 使用经验者加分；
5. 了解 Nginx 配置与调优者优先；
6. 有 AWS 云服务使用经验者优先；
7. 具备良好的故障排查能力与文档习惯。
