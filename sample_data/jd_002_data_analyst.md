岗位职责
1. 负责业务数据的日常提取与清洗，使用 SQL 完成多表关联查询；
2. 使用 Excel 制作业务报表，支持周报月报的数据整理；
3. 参与用户行为分析项目，输出数据分析报告；
4. 协助数据团队维护数据看板。

任职要求
1. 本科及以上在读，统计学、数学、计算机等相关专业优先；
2. 熟练使用 SQL，熟悉 Excel 常用函数与数据透视表；
3. 会使用 Python 进行数据处理者优先，了解 Pandas、NumPy 更佳；
4. 了解 Tableau 或 Power BI 等可视化工具者加分；
5. 每周到岗 4 天以上，实习期不少于 3 个月；
6. 工作认真细致，具备良好的数据敏感度。
